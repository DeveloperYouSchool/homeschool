# Version control  
Software developers often need a way to mark a 'stopping point' in their projects. Using some type of version control system helps you keep track of where you are in your project when stop for either a break or for the day.  
DeveloperYou School will use a product called **git** for version control lessons. This is a free-to-use product and has a large user community.  

## The bigger picture  
Imagine you're putting a puzzle together. My mom used to love those large 3,000 or more piece puzzles. She'd work on them for days or weeks.  
One thing she would do is work on smaller sections of the puzzle and 'stitch' them together later. Sometimes, if she was going to leave the puzzle for a while, she would place the completed sections in the box so they couldn't be disturbed.  

We can use a version control product to save our progress in much the same way.  

Just like mom would work on completing a section and then put it in the box, we can save our progress once we're happy with it and continue later. 

## Saving your place  
Using our example above, once we have a section looking the way we want it, we can save our place and put it to the side so we can work on something else.  
If you've every heard the phrase "commit this to memory", you're already halfway there.  

Imagine you're talking to someone about saving your place:  

"Hey, git, commit this puzzle section to memory, I just finished a piece of the boathouse."  

What you've done is told git to save a piece of your work because you've completed a portion of your work to satisfaction.
